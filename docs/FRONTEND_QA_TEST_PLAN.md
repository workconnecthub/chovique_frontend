**Application**: Chovique Artisanal Chocolates E-Commerce Frontend  
**Framework**: React 19, TypeScript, Vite 8, React Router v7  
**Date**: October 2026  
**Auditor**: Senior Frontend QA & Security Engineer  

---

## 1. Scope and Test Strategy

This document details the comprehensive Quality Assurance (QA), Security, Accessibility, and Cross-Device testing for the Chovique e-commerce web application.

Status Conventions:
- **PASS**: The test case executed and the expected result was verified.
- **FAIL**: The test case executed and the expected result was not achieved.
- **BLOCKED**: The test case could not be completed because a prerequisite (e.g., live SMS gateway, external payment gateway webhook) was unavailable.
- **NOT RUN**: The test case has not been executed yet.
